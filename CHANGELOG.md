# Changelog

## 1.0.0-beta.1

- Added adaptive phone, tablet, expanded, and desktop browser layouts.
- Added freeform-window resizing support for Android desktop environments.
- Added a Safari-inspired visual tab overview with tab cards.
- Added a dedicated full-screen settings area.
- Added an anchored overflow menu with grouped browser actions.
- Kept compact browser controls above the software keyboard.
- Fixed Gecko helper-process startup crashes.
- Fixed native Aether pages being replaced by Gecko's initial blank page.
- Added independent Gecko-backed browser tabs and common desktop shortcuts.

This beta is intended for sideloading and testing. Website permission prompts and additional
browser data surfaces are planned for later releases.
